# Data Integration & Business Intelligence

**Professional Internship Project | Data Engineering & Analytics**

## Project Overview

This project was carried out as part of a professional internship within a public-sector administration in Madagascar.

The objective was to design and implement a data integration workflow to prepare, clean, transform, and load structured data into a data warehouse, making it available for analytical purposes and business intelligence reporting.

The project combined Python-based data preparation, ETL development, database integration, data validation, and dashboard creation.

## Project Workflow

The workflow consisted of the following stages:

1. **Data Preparation:** Monthly Excel files were processed using Python and Pandas to clean, standardize, and harmonize textual and numerical values.
2. **ETL Development:** An ETL workflow was designed using Talend Open Studio to automate data integration.
3. **Database Integration:** Processed data were loaded into an Oracle-based data warehouse.
4. **Data Validation:** SQL queries were used to verify data completeness, record counts, and the availability of analytical fields.
5. **Business Intelligence:** Integrated data were explored through analytical indicators and visualizations using Wise Intelligence.

## Key Contributions

- Developed Python scripts with Pandas for data cleaning and standardization.
- Prepared and consolidated multiple Excel datasets.
- Designed an ETL workflow using Talend Open Studio.
- Worked with Oracle Database 21c XE and SQL Developer.
- Performed data quality checks and validated data integration.
- Contributed to the creation of analytical indicators and dashboards in Wise Intelligence.
